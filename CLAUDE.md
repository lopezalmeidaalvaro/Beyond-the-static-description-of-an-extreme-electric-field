# Instrucciones del repositorio

- **Autor** de todo documento científico generado aquí (paper, informes, auditorías, README): **Álvaro López Almeida**.
  No inventar afiliación ni correo; si hace falta, dejar el campo fuera y avisar.

- Toda cifra de un documento debe salir de `discovery_results.json` (ver `07_make_report.py`, `10_build_paper.py`).
- `./run_all.sh` debe terminar con exit 0 antes de cualquier commit.
